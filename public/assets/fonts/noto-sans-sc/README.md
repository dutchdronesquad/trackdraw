# Noto Sans Simplified Chinese

`NotoSansSC-VF.ttf` is the variable TrueType font distributed as Noto Sans Simplified Chinese by Google Fonts.

- Source: `https://github.com/google/fonts/tree/main/ofl/notosanssc`
- Upstream font project: `https://github.com/notofonts/noto-cjk`
- License: SIL Open Font License 1.1, included in `OFL.txt`
- SHA-256: `a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`

TrackDraw loads this asset only when generating a Simplified Chinese PDF. It is not used as a general UI font.
