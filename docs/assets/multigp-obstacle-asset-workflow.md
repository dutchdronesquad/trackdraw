# Obstacle assets

Source models, texture production, attribution and publishing are maintained in [dutchdronesquad/track-assets](https://github.com/dutchdronesquad/track-assets). Follow that repository's README and documentation when updating artwork.

TrackDraw keeps procedural geometry, official dimensions, catalog identities and panel orientation in its own catalog and renderers. Preview, flythrough and the online viewer use `https://assets.trackdraw.app/multigp/<filename>.webp`. Stable filenames are shared by consumers; there are no asset release pins or sync commands in this repository.

A manual `.tdviewer.zip` export captures the current required textures and their hashes. The resulting file can be opened offline without contacting the asset host.
