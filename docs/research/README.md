# Research

Research is grouped by implementation status, assessed against the current repository on September 12, 2026. Start here to distinguish existing foundations from unfinished work. The [active roadmap](../roadmap/ROADMAP.md) owns priorities and [PVAs](../pva/) own implementation plans.

`implemented` means the documented foundation exists in code, not that every suggested extension is complete or production acceptance has been verified. Research retains its original context; use the scope notes below when older passages describe implementation as future work. Maintained contracts remain authoritative in their stated domain.
