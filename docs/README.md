# Docs

TrackDraw documentation is grouped into a few focused areas:

- [Contributing](../CONTRIBUTING.md)
  Contributor setup, development modes, commands, and validation guidance.

- [roadmap/](./roadmap/)
  Product direction, sequencing, and roadmap tracking.

- [deployment/](./deployment/)
  Runtime, Cloudflare, D1, and local development workflow.

- [research/](./research/README.md)
  Research grouped by implemented foundations, work in progress, and planned or parked directions.

- [pva/](./pva/)
  Product vision and action documents for specific feature areas.

The [Desktop Workspace PVA](./pva/desktop-workspace-pva.md) describes the proposed move toward desktop as the main design workspace, a continuing role for web editing and sharing, and delivery phases that preserve the current codebase structure.
